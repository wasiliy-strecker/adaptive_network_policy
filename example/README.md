# Adaptive Network Policy example

An interactive dashboard for the package's native signals and deterministic
policy decisions.

- Android, iOS, and macOS start in live mode and can switch to simulation.
- Web starts in simulation because it is a documentation target, not a plugin
  runtime target.
- Six scenarios exercise four operation profiles and expose defer reasons.

Run the browser demo:

```sh
flutter run -d chrome
```

Run widget tests:

```sh
flutter test
```
