# Security policy

## Supported versions

Security fixes are applied to the latest released minor version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository rather
than opening a public issue. Include the affected platform, package version,
impact, reproduction steps, and any suggested mitigation.

The plugin does not send probe requests or collect network identifiers. A
security report is still appropriate for permission misuse, channel validation
problems, denial-of-service behavior, or an unexpected disclosure by native
code.
